# UDA-Hub: multi-agent customer support with LangGraph

Udacity *Agentic AI* project (LangGraph multi-agent course, cd14641).

* **`solution/`**: the submission. Start with [`solution/README.md`](solution/README.md).
* `starter/`: the unmodified starter code, kept for reference.

Quick start:

```bash
cd solution
pip install -r requirements.txt
cp .env.example .env        # add OPENAI_API_KEY
python scripts/setup_databases.py
python 03_agentic_app.py demo
pytest
```
